# Backend RAEC

Este directorio contiene el código fuente del backend para el proyecto RAEC.

## Estructura de carpetas

- **controllers/**: Controladores que gestionan la lógica de las rutas y peticiones.
- **core/**: Componentes centrales como modelos, esquemas y la configuración de la base de datos.
- **routes/**: Definición de rutas de la API.
- **services/**: Servicios que implementan la lógica de negocio.
- **utils/**: Utilidades y funciones auxiliares (por ejemplo, autenticación).
- **Lista.txt**: Archivo de lista auxiliar.
- **loader.py**: Script de carga o inicialización.
- **main_backend.py**: Punto de entrada principal del backend.

## Requisitos

- Python 3.10+
- Instalar dependencias con:
  ```bash
  pip install -r requirements.txt
  ```

## Ejecución

Para iniciar el backend:

```bash
python main_backend.py
```

## Descripción general

El backend implementa una API para la gestión de profesores y otros recursos relacionados. Utiliza una arquitectura modular basada en controladores, servicios y rutas para facilitar el mantenimiento y la escalabilidad.
